# rust_lib_reader_nover

Flutter FFI 插件的预编译原生库容器。

- Android 库位于 `android/src/main/jniLibs/`。
- iOS XCFramework 位于 `ios/Frameworks/RustCore.xcframework/`。

当前产物来自 `/Users/jumuning/Personal/App-end/reader_nover/rust` 的 `main`
分支提交 `444a664`。

本目录不执行 Cargo、Rust 或 CargoKit 构建步骤。
